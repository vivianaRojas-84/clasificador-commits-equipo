# Clasificador de Commits con Inteligencia Artificial

## Descripción del proyecto

Este proyecto busca desarrollar una solución de inteligencia artificial capaz de clasificar mensajes de commits de Git según el tipo de cambio realizado en un proyecto de software.

La solución utilizará un modelo de lenguaje local mediante Ollama y una API desarrollada con FastAPI.

## Objetivo general

Implementar una solución de inteligencia artificial que permita clasificar automáticamente mensajes de commits, facilitando la organización del historial de cambios de un proyecto.

## Tecnologías

- Git y GitHub: control de versiones.
- Python: lenguaje de programación.
- Ollama: ejecución local del modelo de inteligencia artificial.
- FastAPI: desarrollo de la API.
- Docker: contenedorización.
- PostgreSQL: almacenamiento de información.

## Categorías de clasificación

- feat: nuevas funcionalidades.
- fix: corrección de errores.
- docs: cambios en la documentación.
- test: pruebas de software.
- chore: tareas de mantenimiento.
- refactor: reorganización del código.
